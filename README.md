# Моделирование эволюционного развития популяции на Godot

Работа создана при помощи [Godot v4.6.2 stable](https://godotengine.org/download/archive/4.6.2-stable/).

Основной сценой демонстрации является `main_scene.tscn` (установлена как сцена по-умолчанию).

## Структура

- `addons/` - используемые аддоны;

- `config/` - задаваемые параметры симуляции (в основном кривые зависимостей между параметрами);

- `etc/` - вспомогательные скрипты;

- `genetic/` - набор функций и классов генетического алгоритма, используемого для эволюции популяции;

- `organism/` - скрипты и сцены организма, в том числе парсер генома организма и отдельные органы (модули) организма;

- `tests/` - тесты, в осном для функций ГА;

## Используемые аддоны

- [GDScript Formatter](https://github.com/GDQuest/GDScript-formatter) - форматирование скриптов

- [SignalVisualizer](https://github.com/Ericdowney/SignalVisualizer) - визуализация графов сигналов для отладки

- [Beehave](https://github.com/bitbrain/beehave) - деревья поведения, использовались для поведения организма

- [GUT](https://github.com/bitwes/Gut) - для unit-тестирования

- [Log.gd](https://github.com/russmatney/log.gd) - улучшенные логи (для отладки)

## Запуск проекта

1. Необходимо скачать движок [Godot v4.6.2 stable](https://godotengine.org/download/archive/4.6.2-stable/).

2. Клонировать (скачать) проект.

3. [Опционально] Через редактор движка изменить параметры кривых в `config/` или изменить параметры в сценах модулей в `organism/` (например, `organism/body.tscn`).

4. Запустить `main_scene.tscn`
